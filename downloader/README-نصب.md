# دکمه‌ی دانلود CubeVPN — راهنمای نصب

## قدم صفر (بدون این، هیچ‌کدام از قدم‌های بعدی جواب نمی‌دهد)

در ریلیز v1.7.7 روی گیت‌هاب **فایل APK وجود ندارد**. آن دو موردی که زیر
«Assets 2» می‌بینید — `Source code (zip)` و `Source code (tar.gz)` — را خودِ
گیت‌هاب خودکار می‌سازد و سورس هستند، نه اپلیکیشن.

پس اول باید فایل نصبِ ساخته‌شده را به ریلیز اضافه کنید:

    Releases → v1.7.7 → Edit (مداد) → Attach binaries → فایل .apk را بکشید

اگر خروجی بیلد چند فایل معماری‌دار دارد، `universal` را هم آپلود کنید؛
اسکریپت خودش universal را ترجیح می‌دهد چون روی همه‌ی گوشی‌ها نصب می‌شود.

## قدم ۱ — فایل‌ها

هر سه فایل را کنار `index.html` صفحه‌ی دانلود بگذارید:

    downloader/cubevpn.php
    downloader/cubevpn_config.php     ← از روی نمونه بسازید
    downloader/.htaccess              ← اگر از قبل .htaccess دارید، محتوایش را اضافه کنید

## قدم ۲ — توکن

`cubevpn_config.sample.php` را به `cubevpn_config.php` تغییر نام دهید و
توکن را داخلش بگذارید. طرز ساختن توکن داخل خود همان فایل توضیح داده شده:
یک Fine-grained token با دسترسی **فقط‌خواندنیِ Contents** روی **فقط**
مخزن `cubepy/CubeVpn`.

## قدم ۳ — دکمه‌ی صفحه

در `index.html` دکمه‌ی «دانلود CubeVPN» را به این تغییر دهید:

    <a href="cubevpn.php" class="...">دانلود CubeVPN</a>

اگر جاوااسکریپتی دارد که به `api.github.com` می‌زند، آن را حذف کنید —
دیگر لازم نیست و از مرورگرِ بازدیدکننده هم کار نمی‌کند.

## قدم ۴ (اختیاری) — نمایش شماره‌ی نسخه

اگر می‌خواهید مثل کارت v2rayNG شماره‌ی نسخه را نشان دهید، به عنصری که
باید نسخه داخلش بنشیند `id="cubevpn-version"` بدهید و این را ته صفحه اضافه کنید:

    <script>
    fetch('cubevpn.php?info=1')
      .then(r => r.json())
      .then(d => {
        if (!d.ok) return;
        var el = document.getElementById('cubevpn-version');
        if (el) el.textContent = d.version + (d.size_mb ? ' — ' + d.size_mb + ' مگابایت' : '');
      })
      .catch(function () {});
    </script>

## تست

    https://alirezapc.ir/downloader/cubevpn.php?info=1

باید JSON بدهد با نسخه و حجم. اگر خطا داد، متنِ خطا خودش می‌گوید مشکل کجاست
(توکن تنظیم نشده / فایل APK در ریلیز نیست / دسترسی برقرار نشد).

## نکته

بار اولِ هر نسخه، فایل از گیت‌هاب گرفته و روی سرور شما کش می‌شود
(`.cubevpn-cache/`). از آن به بعد بازدیدکننده‌ها مستقیم از سرور شما دانلود
می‌کنند — نه از گیت‌هاب. برای مخاطبِ این صفحه که هنوز VPN ندارد این مهم‌ترین
بخش ماجراست. کش خودش فایل‌های قدیمی‌تر از ۳۰ روز را پاک می‌کند.
